\paragraph{Current subquestion.}
Determine the number of all possible arrangements of the functional groups on a hexadifferentiated α-CD (assume only the CH2OH groups have been modified).

\paragraph{Recorded answer/context.}
If we have 6 linear positions for 6 coloured balls, the total number of arrangements will be 6! = 720. But in α-CD, positions are in a circle, which makes all arrangements below equal. The correct answer 6!/6 = 120. Correct answer 4 points; if the answer 720 or 60– 2 points, if answer 320 - 1 point. All other answers - 0. 4.0 pt

\begin{proof}
\leanok
Model the six glucopyranose positions of the $\alpha$-CD macrocycle as
$\mathbb{Z}/6$ (\texttt{CDPosition}) and the six pairwise distinct functional
groups as \texttt{Fin 6}; an arrangement is a bijection
\texttt{CDPosition $\simeq$ FuncGroup}.  Molecular identity is equality up to
precomposition with a translation $x \mapsto x + k$ of the ring
(\texttt{SameMolecule}), which forms a setoid (\texttt{arrangementSetoid})
because translations form a group (\texttt{rotateBy\_zero},
\texttt{rotateBy\_add}).  There are $6!$ labelled arrangements
(\texttt{card\_arrangements}: $\mathrm{card}(\alpha \simeq \beta) =
(\mathrm{card}\,\alpha)!$).  The rotation action is free
(\texttt{rotateBy\_eq\_self\_iff}): a rotation fixing an arrangement fixes the
group at every position, hence is the identity by bijectivity.  So every
equivalence class has exactly $6$ elements (\texttt{card\_arrangement\_class}),
and the map $(q, k) \mapsto \mathrm{rotateBy}\ k\ q.\mathrm{out}$ from
\texttt{Quotient arrangementSetoid $\times$ CDPosition} to arrangements is a
bijection, giving $\#\text{molecules} \cdot 6 = 6!$, i.e. $6!/6 = 120$
(\texttt{arrangement\_count\_eq}, \texttt{arrangement\_count}).  Reflections
are not quotiented out, matching the marking scheme's answer $6!/6 = 120$
rather than $6!/12 = 60$.
\end{proof}
