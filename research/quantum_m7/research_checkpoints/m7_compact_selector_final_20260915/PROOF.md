## Claim

Integrated compact arithmetic selector theorem. For every finite N≥1 and 1≤w≤N, the construction below generates exactly the connected cyclic two-block GF(2) recipe classes meeting the requested full-signature sectors and returns all optimal classes, all requested optimal action records, and every distinct requested optimal ordered physical presentation. Equivalence is exactly independent translations, one common unit multiplier, and block exchange. Generation uses factorized group-numerator/full-stabilizer prefix counts and one recovered leaf per class, without Cartesian support-pair enumeration or expanded pair-orbit storage. Exact distance, logical witnesses, signature transport, realizable joint locality, ties, empty answers and terminating certificate replay are included. This uniform mathematical composition proves original M7 at symbolic constructive-selector strength, using the explicitly derived finite-order M5 arithmetic and M6 exact reduction. Fresh independent dual reviews of this exact candidate are pending at author time. Full implementation of every query and replay feature, arbitrary-span efficiency (M8), practical superiority and Lean certification are outside this symbolic claim.

2. Domain, query and equivalence.
Write M=x^N+1 and R=GF(2)[x]/(M). A recipe is an ordered pair (A,B) of w-element subsets of Z/NZ. Its polynomial signature is F=gcd(a,b,M), where a=Σ_{i∈A}x^i and b=Σ_{i∈B}x^i, with full multiplicities. Connectedness means that all within-block differences generate Z/NZ. For anchored supports containing zero this is gcd(N,A,B)=1.

The abstract group G=(Z/NZ)^2⋊(U(N)×C2) has action records g=(u,ε,s,t) and action g(A,B)=(uA_ε+s,uB_ε+t), where ε exchanges the blocks. At N=1, U(N) is the singleton identity and the abstract exchange element is retained. Thus |G|=2φ(N)N² even when the action has a kernel. The relations M_uT_{s,t}=T_{us,ut}M_u, ET_{s,t}=T_{t,s}E and EM_u=M_uE establish the stated normal form. All operations are invertible. Connectivity is invariant because translations preserve differences, units carry their generated subgroup isomorphically, and exchange merely reorders them.

A default query specifies allowed dimensions K⊆{0,…,2N}, a set E of distinct monic divisors of M or all signatures, an optional integer distance floor, optional nonnegative caps on L and R_loc, and a list of objective coordinates from (L,R_loc,−k,−d), minimized in Pareto or lexicographic order. An empty objective list makes all feasible records tied. Invalid signature inputs are rejected; w>N has empty support domain, and nonpositive weights are outside this theorem.

Class-sector semantics admits a class if some orbit member has signature in E; its sector witness need not be the returned optimal placement. Placement-sector semantics requires each returned presentation itself to have signature in E. These are explicit distinct query modes. Distance is either an integer or NoLogical. A distance floor or a −d objective excludes NoLogical; otherwise k=0 is allowed when 0∈K. No infinite numerical distance is assigned.

Extensions require specified total computable predicates, objective functions and exact comparison procedures with terminating sound evaluation verifiers. Class functions must be invariant. In distinct-presentation mode, placement functions must depend on the realized ordered supports, not on redundant action encodings. Action-dependent extensions require action-output mode or separate quotient semantics.

3. Canonicalization and signatures, uniformly including even N.
For a nonempty support C define ν(C)=min_{q∈C} sorted(C−q). This is the least translate: some translate contains zero, and any increasing tuple beginning with zero precedes every tuple beginning positively. Independent translation minima decouple. Consequently κ(A,B)=min_{u,ε}(ν(uA_ε),ν(uB_ε)) is the least full-orbit member. The set minimized is unchanged by a group action. Equal minima give invertible actions relating the inputs, so κ is a complete invariant for exactly G. Retain a minimizing action and its inverse. This involves separate single-block anchor loops, not a product of translation choices.

By polynomial Bézout, the ideal (a,b) in R is (F). Translations multiply its generators by units, and exchange preserves it. For u∈U(N), substitution σ_u(x^i)=x^{ui mod N} is a ring automorphism. Hence the signature after g is exactly τ_u(F)=gcd(M,σ_u(F)). Uniqueness of the monic divisor generating an ideal gives τ_vτ_u=τ_{vu}. Since dim_GF(2)(F)=N−deg F and σ_u is a vector-space bijection, deg τ_u(F)=deg F. This argument works in the nonreduced quotient ring and retains repeated factors; no root-set or squarefree inference is used. A class meets E precisely when some τ_u(F) belongs to E. Such a unit, with zero shifts and no exchange, supplies a realizing action, whose literal gcd can be checked directly.

4. Exact anchored prefix counts.
A prefix fixes the membership bits at positions 1,…,N−1 of A, followed by B, with zero always selected. Let D_A,D_B be the selected sets and W_A,W_B the undecided sets, disjoint from the selected sets. Excluded positions belong to neither. Put k_A=w−|D_A| and z_A=Σ_{s∈D_A}x^s, and similarly for B.

For monic P with P(0)=1 and D=deg P define
n(P,W,k,z)=2^(−D) Σ_{λ∈GF(2)^D} (−1)^{λ·(z mod P)} [t^k] ∏_{s∈W}(1+t(−1)^{λ·(x^s mod P)}).
Impossible cardinalities give zero. For P=1 there is one character and this is binom(|W|,k). Expanding the coefficient selects each k-element subset once. Averaging its character is one when its residue sum equals z and zero otherwise: for a nonzero difference, toggling a corresponding coordinate of λ pairs opposite signs. Thus n counts exactly the required subsets. It can be evaluated without subset enumeration: if n_− and n_+ count negative and positive signs, the coefficient is Σ_j(−1)^j binom(n_−,j)binom(n_+,k−j).

For F|M set
C_F(p)=Σ_{d|gcd(N,D_A,D_B)} μ(d) Σ_{H|rad(M/F)} (−1)^ω(H) n(FH,W_A∩dZ,k_A,z_A)n(FH,W_B∩dZ,k_B,z_B),
where H ranges over squarefree monic divisors. Define C_E(p)=Σ_{F∈E}C_F(p).

For each completed pair, the integer-divisor sum contributes Σ_{d|gcd(N,A,B)}μ(d), exactly its connectivity indicator. Conditional on F dividing both polynomials, each irreducible q whose multiplicity in F is below its cap in M contributes exclusion of simultaneous divisibility by q^{v_q(F)+1}. Expanding these exclusion factors is exactly the H sum. Always FH|M, including at even N. The two n factors independently count the block completions satisfying these conditions. Therefore C_F(p) counts exactly connected anchored completions with full gcd F. Distinct signatures are disjoint. Thus C_E is a nonnegative integer, partitions into its two child counts, and is zero or one at a leaf. This proves the invoked M5 finite-order interface directly; no global birth theorem is assumed.

5. Factorized orbit-prefix theorem.
Fix a stored canonical representative c=(A,B). For each u,ε let α_c(u,ε,p) count shifts s for which uA_ε+s satisfies D_A⊆C⊆D_A∪W_A, and let β_c(u,ε,p) count the analogous shifts t for the other block. Count shifts, including multiple shifts with the same image. Each number requires only a single-block loop.

Define J_c(E,p)=Σ_{u,ε}1[τ_u(F_c)∈E]α_c(u,ε,p)β_c(u,ε,p). At fixed u,ε, the admissible translation choices form a Cartesian product; multiplying their cardinalities counts it without traversing that product. Signature membership depends only on u. Consequently J_c counts precisely the group elements whose images satisfy the anchored prefix and signature query.

Compute h_c by the same numerator with no signature condition and with the two target conditions exact equality to A and B. It counts precisely Stab_G(c), so h_c≥1 and is the full stabilizer. For every orbit image y=g_0c, h↦g_0h bijects Stab_G(c) with {g:gc=y}. Hence
O_c(E,p)=J_c(E,p)/h_c=|Gc∩X_E∩[p]|,
where X_E is the connected anchored domain with signatures in E. This proves integrality, distinct-member counting and child partition. Periodic supports, identical blocks and a nonfaithful action cause no exception: their multiplicities occur in both numerator and full stabilizer.

6. Compact generation, recovery and coverage.
Maintain a list T of distinct canonical representatives and define
R_T(p)=C_E(p)−Σ_{c∈T}O_c(E,p).
Initially T is empty. If the root residual is zero, stop. Otherwise keep T fixed and descend the prefix tree, choosing child zero if its residual is positive and child one otherwise. At a positive full leaf y, append κ(y), together with y, both signatures and a realizing action, then restart at the root.

Inductively the emitted orbits are disjoint and
R_T(p)=|(X_E∩[p])\⋃_{c∈T}Gc|.
Initially this follows from the count formula. Under the induction hypothesis it proves nonnegativity and child partition. Every positive parent has a positive child. A positive leaf has residual one, lies in X_E and belongs to no emitted orbit; its canonical form is therefore new. Appending it preserves the invariant. Each insertion covers at least its chosen leaf, and the domain is finite. More precisely there is exactly one descent per orbit meeting X_E. Final zero root residual proves coverage of X_E. Every raw queried orbit has an anchored member, because independent translations anchor its nonempty blocks without changing its signature. Therefore the output is precisely the required structural transversal, even when a canonical signature lies outside E.

For all-signature queries take E to be every divisor of M. For signature-restricted queries generation covers every orbit meeting E before dimension, distance, locality or objective rejection. No class is removed on those quality grounds before its exact labels are computed. Sequential singleton-sector generation also works if all previously emitted representatives are retained: the same invariant applies to each sector, and later insertions cannot destroy earlier coverage.

At w=1 the only anchored pair is ({0},{0}); it is connected only for N=1 and has signature 1. At N=1 the prefix has depth zero, h_c=2, the qualifying numerator is 2 and O_c=1. Empty E yields zero counts. All arguments also cover w=N and periodic supports.

7. Exact distance and witnesses: the checked M6 strength.
For each generated c let f=deg F_c. Define B=im[h↦(ah,bh)] and C=ker[(v,z)↦bv+az] in R². Commutativity gives B⊆C. Bézout gives ker(h↦(ah,bh))=ker(h↦F_ch). Writing M=F_cK, polynomial cancellation gives M|F_ch iff K|h. There are exactly 2^f such residues h; thus dim B=N−f and every boundary has 2^f preimages.

For the stipulated circulant convention J(v,z)_i=(z_{−i},v_{−i}) is an orthogonal weight-preserving involution with C=(JB)^⊥. Therefore dim C=N+f, k=2f, and J interchanges the X and Z cycle/boundary pairs.

Put r_c=max(deg a,deg b)<N. A memory of r_c preceding input bits receives t∈{0,1}, outputs α=a_0t+Σ_{j≥1}a_jm_j and β=b_0t+Σ_{j≥1}b_jm_j in GF(2), then shifts. Retain both labeled loops when r_c=0. Closed length-N labeled walks correspond bijectively to indexed cyclic inputs: the shift equations force m_{i,j}=h_{i−j}. No rotation division occurs. Matrix entries sum weights over parallel edges.

Let T have edge weight y^{α+β} and U have weight (1+y)^{2−α−β}(1−y)^{α+β}. The boundary enumerator is 2^(−f)tr(T^N). For any binary space D, character orthogonality gives E_{D⊥}(y)=|D|^(−1)Σ_{q∈D}∏_j(1+(−1)^{q_j}y). Applying this to D=JB and parameterizing its elements by h gives normalization 2^(−N): |JB|=2^{N−f} and each element has 2^f preimages. Consequently
Q(y)=2^(−N)tr(U^N)−2^(−f)tr(T^N)=Σ_{z∈C\B}y^{wt(z)}.
The divisions are exact coefficientwise. Q has nonnegative integer coefficients, Q(0)=0 and Q(1)=2^{N+f}−2^{N−f}. At f=0 it is zero and returns NoLogical; otherwise its first positive coefficient gives the minimum nonboundary-cycle weight. J equates the two type distances. Every nontrivial CSS Pauli has a nonboundary X or Z component supported inside its total support, and a pure minimum logical attains this lower bound. Thus the extracted value is physical quantum distance.

For constructive witnesses, give each coordinate q an allowed set A_q⊆{0,1}. Define b_q(s)=1[s∈A_q]y^s and c_q(s)=Σ_{z∈A_q}(−1)^{sz}y^z. At layer i use boundary weight b_{L,i}(α)b_{R,i}(β) and character weight c_{R,−i}(α)c_{L,−i}(β). The swapped inverted indices are forced by J. Their normalized trace difference Q_P counts pinned nonboundary cycles. Splitting a free coordinate gives Q_P=Q_{P,q=0}+Q_{P,q=1}. Starting with [y^d]Q>0, keep a zero pin whenever its coefficient stays positive, otherwise keep one. After 2N decisions exactly one weight-d nonboundary cycle remains. Direct syndrome and binary row-space checks verify it; applying J supplies a Z witness.

Translations carry X cycles and boundaries by (v,z)↦(x^sv,x^tz), multiplying the syndrome by x^{s+t}. Common units apply σ_u to both blocks and exchange swaps them. These coordinate permutations preserve weight and transport witnesses. The corresponding Z transformation is obtained through J. Thus labels are class invariants; no module shear is treated as a weight isometry. These derivations use full multiplicities and no finite catalogue labels.

8. Realizable locality and every optimum.
For residues i let δ(i)=min(i,N−i). For each c,u and each block independently, compute arrays l(s)=Σ_{i in block}δ(ui+s) and r(s)=max_{i in block}δ(ui+s). An action g=(u,ε,s,t) has L_c(g)=l_{A_ε}(s)+l_{B_ε}(t) and R_loc,c(g)=max(r_{A_ε}(s),r_{B_ε}(t)). Both values belong to the same actual ordered presentation. Separate minima are never substituted for this joint point.

After certifying every structural candidate and its labels, let Feas(c,g) be the conjunction of the query tests, including its selected sector mode and locality caps. Let z(c,g) be its objective vector. Define the executable finite predicate
Win(c,g) ⇔ Feas(c,g) and no feasible (c′,g′) has a strictly better objective vector.
Pareto strictness means coordinatewise ≤ with at least one strict coordinate; lexicographic strictness has its usual meaning. Return precisely the classes with a winning action and the exact predicate describing all their winning actions, with query parameters, labels, logical witnesses and required sector witnesses. Requested action expansion loops over all indices and outputs every winning index. Scalar comparisons need no support-pair orbit ledger.

Every output is feasible and undominated. Conversely, any globally optimal feasible raw presentation belongs to a unique generated class, and the group normal form supplies an action realizing exactly that presentation. Its labels, literal placement signature and joint locality values agree. It therefore satisfies Win. This proves completeness for every tied class and action. A finite nonempty feasible set has an undominated element, since a strict improvement chain cannot repeat. Thus an empty winning set is equivalent to an empty feasible set, after structural coverage is certified. Every feasible nonwinner has a winning strict dominator by following such a chain. No per-block domination pruning is used: strict improvement in a block range can disappear under the joint maximum and would otherwise lose physical ties.

9. Duplicate-free physical presentation reconstruction.
Order action records lexicographically. For a target q=(C,D) in the orbit of c and fixed v,η, compute separately S_{v,η}(C)={s:vA_η+s=C} and T_{v,η}(D)={t:vB_η+t=D}. If both are nonempty, their independent minima give the least action for this v,η realizing q. Minimize these candidate records over v,η and call the result λ_c(q). This is the least preimage of q because its preimages at fixed v,η are exactly S×T. The computation uses separate single-block loops and a current target, not translation-pair enumeration or an expanded orbit set.

Define Present(c,g) ⇔ Win(c,g) and g=λ_c(g·c). All preimages of a physical presentation have identical default feasibility and objective values, and likewise for the permitted presentation-based extensions. Hence every winning presentation has a winning least preimage, and exactly that preimage passes Present. Distinct generated classes cannot yield the same ordered presentation. Output supports and transported witnesses only for accepted indices. This returns every distinct winning ordered presentation once, including periodic and identical-block cases. Both swap records remain available in action mode; presentation mode removes their duplicate when they coincide. Reconstruction is checked by C=uA_ε+s and D=uB_ε+t and their inverse equations.

10. Replay certificate and soundness.
The certificate specifies the query and modes, factorization of M, deterministic orders, emitted leaves and descent paths, canonical representatives and actions, stabilizers and signature transport, final zero residual, exact Q coefficients or recurrence data, pin decisions and logical witnesses, and the executable Win/Present representation. Recorded numbers and hashes are not trusted as proofs.

Replay verifies the factor product and irreducibility by finite polynomial division; enumerates units; recomputes the character counts, inclusion-exclusion, factorized numerators and full stabilizers; and checks exact divisions. In emission order it checks both child residuals, their partition, the positive branch, direct leaf validity, canonical minima, distinctness and action reconstruction. It then checks the final zero root residual. The disjoint-subset invariant proves coverage from these checks; mere equality of list lengths would not.

For every structural class, replay recomputes its gcd and transported signatures, the exact trace recurrence through degree 2N, its first positive coefficient or NoLogical, and the pin choices. It checks physical witness weight, syndrome and nonboundary status independently. It traverses all action indices to evaluate feasibility and exact objective comparisons, verifies all winners and all omitted-record reasons, and reconstructs strict winning dominators for feasible nonwinners. Presentation replay also recomputes λ. Any expanded answer must equal this predicate expansion, including all ties. Empty answers require the verified feasible set to be empty. All loops and arithmetic are finite and specified, so the verifier terminates without an unsolved default-label oracle.

11. Resources and exact no-raw-scan boundary.
Let H be the number of emitted classes, m=2(N−1), φ=|U(N)|, s=|E|, r=ω(M), and P=2φN². At most T_0=1+H(2m+1) residual evaluations suffice, with at most HT_0 compact orbit-count evaluations. Each factorized numerator or stabilizer costs O(φN²) elementary mask-entry operations using separate shift loops. A deliberately conservative bound for one arithmetic prefix count is O(N⁴sτ(N)2^{r+N}) arithmetic operations. Integer and polynomial factorization, units, divisors, binomial coefficients and the actual integer bit costs are additional, finite preprocessing and arithmetic costs. No polynomial-time claim follows.

Generation stores representatives, selected leaves, actions, stabilizers and optional unit-signature tables, using O(HN+HφN) bits plus integer bookkeeping and optional path transcripts. The union of emitted orbits occurs only in the proof invariant. There is no orbit-member cache or support-pair trie. Exactly H complete leaves are recovered; the algorithm does not traverse every positive leaf. This is not a guarantee that H is always much smaller than the number of anchored pairs.

For class c, the transfer recurrence has 2^{r_c} starts, N layers, at most 2·2^{r_c} edges per layer, O(N) coefficients, and O(N)-bit signed accumulators. Distance costs O(N³4^{r_c}) and pinning O(N⁴4^{r_c}) in the indexed-array bit model, with reusable O(N²2^{r_c}) storage. Sum work over all H classes. Locality uses single-block arrays. Pairwise comparison of the HP action records costs O((HP)²(m_obj+1)B) with actual coordinate bit length B; two cursors suffice instead of a record ledger. Least-preimage reconstruction adds separate unit/single-block shift loops for each winning action tested. All explicitly requested output has its own size cost.

Selection therefore evaluates action indices, potentially very many, but does not generate structural candidates by a Cartesian support-pair scan or retain expanded pair orbits. If the user requests all physical ties, the output itself may contain a large part of the raw domain. That unavoidable output expansion is disclosed, not counted as a compact internal representation. M8 efficiency, practical superiority and Lean are not prerequisites.
