# Exact canonical quotient for cyclic two-block recipes

## Claim and scope

This note proves a uniform reduction theorem for the following declared
construction class.  It does **not** classify all quantum codes.

Fix an odd integer `N`, a support weight `w`, and the cyclic quotient group

```text
C_N = Z/NZ,                 R_N = GF(2)[z]/(z^N-1).
```

A raw construction word is an ordered pair `(A,B)` of `w`-element subsets of
`C_N`.  It defines the cyclic two-block CSS presentation

```text
H_X = [a(P) | b(P)],        H_Z = [b(P)^T | a(P)^T],
a = sum_{i in A} z^i,       b = sum_{i in B} z^i.
```

For a fixed finite fibre, admissibility may impose any constraints invariant
under the declared action below.  The fibres currently used in this repository
impose connectedness and

```text
2 deg gcd(a,b,z^N-1) = k.
```

The equality with `k` uses odd `N`, for which `z^N-1` is square-free.  The
canonical-quotient theorem itself is purely a statement about finite supports
and does not use square-freeness.

The declared recipe group is

```text
G_N = C_N^2 semidirect (U(N) x C_2),
```

acting by

```text
(A,B) -> (u A + s, u B + t),
(A,B) -> (B,A),
```

where `s,t in C_N` and `u in U(N)`.  The `C_2` generator swaps both blocks and
the two translation coordinates.  These operations induce qubit and check
permutations.  They are the whole equivalence group in this theorem.  General
qubit permutations, stabilizer row equivalence, local Clifford equivalence,
entangling Clifford circuits, ancillas, and code deformation are outside the
quotient.

## Canonical variables

Write each support as its increasing residue tuple.  For a nonempty support
`S`, define

```text
nu(S) = lexicographically least tuple among {S+t : t in C_N}.
```

Equivalently,

```text
nu(S) = min_{x in S} sorted(S-x).
```

The equivalence holds because the least translate must contain zero.  Define
the translation-and-swap reduction

```text
rho(A,B) = sorted_pair(nu(A),nu(B)).
```

The remaining unit action on such unordered pairs is

```text
u . {S,T} = {nu(uS),nu(uT)}.
```

Finally define

```text
kappa(A,B)
  = min_{u in U(N), epsilon in {0,1}}
      (nu(u A_epsilon), nu(u B_epsilon)),
```

where epsilon exchanges the blocks and the minimum is lexicographic.  The
tuple `kappa(A,B)` is the complete canonical variable for the declared recipe
equivalence.

## Theorem: soundness, completeness, and reconstruction

**Theorem.** For every `N`, `w`, and two raw words `x,y`:

1. `kappa` is constant on every `G_N` orbit.
2. `kappa(x)=kappa(y)` if and only if `x` and `y` are related by an element of
   `G_N`.
3. Every canonical word has a raw preimage.  More strongly, canonicalization
   returns a witness `(u,epsilon,s,t)` satisfying

   ```text
   kappa(A,B) = (u A_epsilon+s, u B_epsilon+t).
   ```

   Applying the inverse unit, inverse translations, and inverse swap
   reconstructs the exact ordered raw word.  Thus, if `K` is the set of
   canonical words and `iota:K -> raw` is inclusion, then

   ```text
   kappa o iota = identity_K,
   x = g_x^{-1} iota(kappa(x))
   ```

   for the stored witness `g_x`.
4. Restricting before or after canonicalization by any `G_N`-invariant
   admissibility predicate gives the same quotient.  Therefore support weight,
   connectedness, a target common-factor degree, locality functions minimized
   over the same recipe orbit, and any other explicitly invariant constraint
   can be imposed without losing an admissible class.

### Proof

First, `nu(S)=nu(T)` exactly when `S` and `T` are translates.  The forward
direction follows from translation invariance of the set of translates.  For
the reverse direction, both `S` and `T` are translates of their common normal
form.  Consequently `rho` is a sound and complete quotient by the normal
subgroup generated by the two independent translations and block exchange.

The unit action on `rho` is well-defined.  If `S'=S+t`, then
`uS'=uS+ut`, so `nu(uS')=nu(uS)`.  It is a group action because

```text
nu(u nu(vS)) = nu(uvS);
```

the inner normalization changes `vS` only by a translation, which the outer
normalization removes.  Hence taking the least element of the finite residual
`U(N)` orbit is invariant under every generator of `G_N`.  This proves (1).

For (2), equality of canonical forms supplies an explicit unit, optional swap,
and two translations taking each raw word to the same word.  Composing the
first action with the inverse of the second relates the two raw words.  The
converse is (1).  The minimization explicitly records the winning action; all
its generators are invertible, proving (3).  Finally, an invariant predicate
is constant on every orbit, so an orbit is either wholly admissible or wholly
inadmissible.  This proves (4).  QED.

The theorem remains true for supports with translational symmetry.  Such a
support can have several shifts attaining `nu`; choosing the least shift makes
the witness deterministic, while uniqueness of the canonical word—not
uniqueness of the witness—is what the quotient requires.

## Why the declared operations are code-sound

Independent translations replace `(a,b)` by `(z^s a,z^t b)`.  On `H_X`, this
is the block-column permutation `diag(P^s,P^t)`.  Applying the same qubit
permutation to `H_Z` and then the check-row permutation `P^(-s-t)` produces
exactly the transposed translated blocks.  A unit `u` relabels every cyclic
site by the permutation `i -> ui`, and block exchange swaps the two data
blocks.  Thus every declared recipe action is a CSS-code permutation
equivalence.  The converse in the theorem is deliberately only about this
declared group: a broader code equivalence may merge canonical recipe words.

For a cyclic quotient lattice `Omega ~= C_N`, changing the chosen isomorphism
`Omega -> C_N` composes it with an element of `U(N)`, so the same unit quotient
also removes cyclic-coordinate duplication.  The statement does not identify
noncyclic quotient groups or different physical embeddings merely because
they have the same number of sites.

## Domain boundary and falsifiers

This is a theorem uniform over the parameterized family of finite cyclic
support fibres, not an empirical extrapolation from `C105`.  Its `C105`
instance is also exhaustively witnessed.  It does not yet prove that the
catalogue generator enumerates every admissible word for arbitrary requested
constraints; that separate generator-surjectivity and constraint-filter audit
remains part of Gate 1.

The result is falsified by any of the following:

1. two words related by a declared generator have different `kappa` values;
2. two words with the same `kappa` value cannot be connected by a declared
   action;
3. a forward witness or its inverse reconstruction fails; or
4. a claimed residual orbit violates orbit-stabilizer.

No claim about distance, a predictive quality law, or optimal selection is made
in this outcome.
