# M6 binary Euclidean preprocessing and indexed-array bit cost

This module addresses the original M6 proof's polynomial-time gcd(a,b,M) preprocessing. It defines and verifies a concrete leading-term cancellation recursion over Polynomial (ZMod 2), followed by an explicit Euclidean remainder recursion. It does not call a gcd oracle in the algorithm. The correctness theorem compares its independently computed output with the normalized GCDMonoid gcd. Zero operands, constants, even orders and repeated factors are retained.

rank p is zero for p=0 and natDegree p+1 otherwise. One cancellation is p-q*(C(leadingCoeff p)*X^(natDegree p-natDegree q)), which is a shifted XOR because all nonzero binary leading coefficients are one. The finite denseXor array map is proved equal to its coefficient representation. Dense arrays are faithful under the width invariant, and an explicit increasing-index fold scanRank is proved to compute rank from those coefficients. Thus degree information and cancellation updates have array implementations, rather than free degree or remainder oracles.

The fuel-based remainder recursion records executed cancellations and full-array passes. Its proof establishes c+rank(remainder)≤rank(input). The outer Euclidean recursion records both cancellations and rounds; the former telescope across successive pairs to c≤rank p+rank q, while rounds≤rank q. This permits initially unordered degrees without a new input assumption. Explicit recursive safety predicates ensure every intermediate operand fits the initial fixed array width.

The counters include degree preparation for both fuel initializations: remainder auxiliary passes are2c+1, each complete remainder call adds its initial degree scan, Euclid tests its second operand at each call, and the outer wrapper scans its initial fuel bound. The proved total is therefore2c+3e+2, not the earlier uncharged estimate. A complete array pass uses a length-width range loop. At each coordinate its conservative bit charge is six at-most-width-bit index operations (comparison, offset subtraction, three addresses and index advance) plus four bit operations (two reads, XOR, write). Standard addresses fit within width=N+1 bits; these charges upper-bound both degree scans and XOR-update passes. scanCost is defined by adding these per-cell charges in the loop, and its quadratic bound is proved afterward.

For polynomial degrees≤N, these actual counters imply bitCost≤90(N+1)^3. The shared two-call preprocess computes gcd(gcd a b)M and has cost≤180(N+1)^3, with the first result's degree bound proved before its reuse. The constants are conservative bounds in the original indexed-array bit model. This does not assert timing bounds for Lean's polynomial data structure or Python's dictionary implementation, add a native-code extraction gate, or require practical runtime superiority.

The exact21-node DAG covers the algebra, counters, array correspondence and width safety. Definitions and target types are checked before freezing; the live experiment uses the existing pinned Mathlib, gpt-6-astra medium,16 concurrency cap,5 rounds, both Mathlib and Physlib retrieval, independent exact-target/axiom checking and combined assembly. No new theorem is counted as proved at preflight.
