The actual algorithm computes sparse indexed transfer traces, divides their integer coefficients by the proved exact powers of two, and subtracts the actual boundary enumerator from the actual cycle enumerator. Its pinned solver returns the true CSS Pauli distance and a minimum logical vector; the proved weight-preserving involution gives the other type of witness. Zero signature means no logical distance. The actual rank formula gives k=2 deg F, retaining all factors of gcd(a,b,X^N+1), including multiplicities at even N.

The original resource model is explicit indexed coefficient arrays with bit operations and bounded addresses. The final interface states distance work ≤50000 N³4^R, witness work ≤200000 N⁴4^R, and complete storage ≤16384 N²2^R. Preprocessing of the fixed input, including F and coefficient windows, is shared across pinned queries and charged once. Fixed-span improvement, the connected span-two family, the documented three coordinate isometries, and both memory-zero edge labels are included. These are the original M6 requirements; no Python interpreter or Lean extraction timing guarantee is asserted.
