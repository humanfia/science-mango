# Whole resource interfaces and gates

The canonical `cutoff`, `actual_optimizer_resources` and `tagged_store` components are available. The following downstream targets are prepared; their canonical gates must still be checked before reuse.

1. `M8.BankLayout`: six concrete buffers, 32 named 32(N+1)-bit control words, and the original `M6.Transfer.solveStorage (Cutoff.limit N) N (EuclidStorage.actualPreprocessStorage N)` banks. The allocation is independent of future discovery and reused across queries. Targets: actual storage monotonicity/embedding, payload ≤20000(N+1)^3, and address size ≤32(N+1).
2. `M8.WholeResources.run`: one original Euclid call; optionally one actual weighted discovery call; optionally one actual M6 solve; successful inverse witness transport. Its ghost charge list has at most six actual stage totals. The successful branch charges `actualWitnessWork` instead of adding distance and witness counters. Setup includes clearing the explicit allocation, reading inputs, caching the cutoff and a separate fixed connectivity gcd scan. Public correctness remains on Valid inputs, without a new invalid-input theorem. Targets include projection to `Solver.run`, single-call/early-return behavior, and `indexedWork ≤225000(N+1)^6`.
3. `M8.SequentialStore` (four targets) and `M8.SequentialResources` (two targets): instantiate `TaggedStore.packFrom 0` with the actual `BankLayout.payloadSlots N` allocation and its real `Nat.size` address width. Prove indexed read/write projection and scan charge bounds for this fixed allocation, actual tagged-space ≤2000000(N+1)^4, then recursively accumulate scan allowances over the actual WholeResources stage charges and separately charge address-tag construction. Final target: `sequentialCharge ≤6000000000000(N+1)^12`.

These are standard symbolic binary-operation upper charges, as in the accepted source and M6 indexed contracts, not Lean runtime costs. The sequential charge is derived from concrete tag scans and the actual execution's bounded stage charges; it is not defined as the final polynomial. No freely supplied memory size, evaluator correctness, query count or total work oracle is a final premise.

The exact refined eligible-span trial count 2N|A||B| is not claimed by these components: the existing cutoff lemma is arithmetic only, while DiscoveryResources proves total executed-prefix charge. This does not alter the requested final n^12/n^4 resource gate.
