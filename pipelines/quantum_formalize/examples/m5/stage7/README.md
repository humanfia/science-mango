# Binary character kernel

Section 2 of the unchanged source proof uses all binary linear characters. Here their signs are represented explicitly as products of coordinate signs (-1)^(a*b).val. The targets prove character addition, orthogonality and the exact finite-fibre count after multiplying by 2^D. Dimension zero and empty fibres remain included.

These are coordinate-space identities. Identifying polynomial quotient elements with coordinates, the subset generating polynomial and the Möbius inclusion-exclusion layers are subsequent obligations. This batch does not replace arithmetic formulas by raw support enumeration.
