# Finite prefix partition for recovery

Prove empty-prefix count, terminal count, and sum of next-coordinate branch counts for a finite set of equal-length valid words. This is a semantic helper for discharging the partition and terminal assumptions in stages36/37. It does not replace the arithmetic definitions by raw pair enumeration. Actual conditional C/A must be identified with this semantic helper through exact completion counts and encoding bijections.

The alphabet is any finite type, so Boolean support decisions and period residues share the same partition theorem. Empty alphabets and empty word sets are not excluded.
