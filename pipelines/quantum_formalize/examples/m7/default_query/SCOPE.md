# Actual M7 default query

The query directly computes full polynomial signature from literal supports through M7.Domain.signature, dimension as twice its natural degree, and physical quantum distance through M7.Transport.distance = M6.Final.quantumDistance. This is the actual CSS Pauli union-support minimum, not a free label oracle. Locality is the sum of min(i.val,N-i.val) on both supports; radius is the maximum of their support suprema. Both labels refer to the same realized ordered pair, never separate optimal placements.

The default query includes dimensions, optional full-signature set or all signatures, explicit class-sector versus placement-sector semantics, an integer distance floor, nonnegative locality/radius caps, an arbitrary list of the four original objective coordinates, and actual Pareto/lex comparison. Invalid signature inputs have an explicit Except.error QueryError.invalidSignature answer, distinct from a valid empty winner set. NoLogical is excluded whenever a distance floor or negative-distance objective is requested. Otherwise no distance constraint is imposed; dimension-zero records can remain if all other tests allow them. The objective's zero fallback only totalizes comparison on already rejected NoLogical records when the distance coordinate is requested; no infinite numerical distance is assigned.

Eight exact targets cover the modes, NoLogical policy, literal-image fiber consistency, all winners/empty answers, invalid-input rejection, strict winning dominators, empty-objective ties and unique actual physical presentations. The final target instantiates actual_presentation9; DEPENDENCY_GATE.json and the launch assertion block all model execution until its canonical proof closure is verified. The original definition-only preflight adapter is retained as preflight_adapter.lean for review. After actual_presentation9 became canonical, its nine declarations and ancestors were verified and promoted unchanged; the adapter is no longer imported.
