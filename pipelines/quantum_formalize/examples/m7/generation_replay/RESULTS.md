# Actual generation certificate replay

All seven frozen targets passed normal kernel, exact-target and axiom acceptance. Six passed first live drafts; `checked_coverage` passed its second live draft. The original failed draft is retained. Assembly/environment/experiment gates passed, and all 142 canonical archive files were verified. Only the standard three axioms occur. No mathematical target, definition or assumption changed.

The concrete checker starts from empty bases. For every recorded emission it recomputes the positive root arithmetic residual, both child residuals through `DescentTrace.check`, the exact depth, the endpoint-decoded leaf, canonical representative and realizer, both signatures, and full stabilizer. It inserts the verified representative and checks the next emission against that actual updated state. At the end it recomputes a zero residual and checks the advertised final bases, residual and exhaustion flag.

`step_exact` identifies a successfully checked record with the actual deterministic emission. `run_replay` and `generate_checked` prove the actual generator is accepted. `replay_sound` and `fresh_nodup` prove sequential freshness, valid classes, anchored leaves and no repeated representatives. `checked_coverage` derives coverage of the anchored domain and, for the original positive weight, every raw queried recipe, including an actual action from a stored representative.

Coverage is derived from the actual zero residual and the proved count invariant. No complete-transversal assumption, trusted numeric/hash oracle, parser, extracted executable or additional runtime gate is used. The full original M7 root remains a separate integration claim.
