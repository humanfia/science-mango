# Concrete query sectors

The original optional sector query is implemented exactly: none enumerates all monic divisors of the actual cyclic modulus; some E preserves E unchanged. Multiset powerset precedes toFinset, retaining repeated factors and all divisor multiplicities. Five exact closed targets cover soundness/completeness, validity, and actual full-signature allows equivalence. No squarefree restriction, sector oracle, new feasibility condition or runtime efficiency gate is added. Canonical parent evidence is hash-verified before import.
