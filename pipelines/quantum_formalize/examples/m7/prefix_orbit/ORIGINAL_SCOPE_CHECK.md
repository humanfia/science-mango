# Original prefix-count scope check

The nine proposed targets implement the count bridge in original PROOF.md §§4–6. They are intermediate integration targets; they do not themselves claim termination, one descent per class, raw coverage, or full M7 acceptance.

`Within` is exactly the selected/undecided support interval. `Base` supplies selected zero in both blocks, finite-order bounds and disjoint selected/undecided sets. `ClassValid` means the two prescribed support cardinalities and the single authoritative difference-subgroup connectivity predicate. Its action invariance is a proof obligation, not a caller-supplied oracle.

`orbitCount` uses the actual factorized source-signature numerator divided by the actual full stabilizer. The semantic orbit filter appears in the theorem RHS. `source_count` restricts to valid stored classes and proves agreement with literal anchored prefix completions; no canonical signature-membership assumption is imposed. Thus a canonical representative outside the requested signature set remains allowed when its orbit meets that set.

`residual` is the original integer arithmetic prefix count minus the finite sum over stored representatives. `Normalized` supplies orbit separation through the accepted concrete canonicalizer. The remaining-set identity and nonnegative/positive conclusions use actual supports, actual actions and actual M5 arithmetic, rather than an abstract count oracle. `emitted_class_valid` closes weight/connectivity preservation for insertion; it deliberately does not demand that the canonical signature remain in the requested sector.

The statements retain positive finite order, order one, repeated factors, periodic supports and empty sectors. No squarefree, odd-order, faithful-action or M8 efficiency hypothesis is added. Parent canonical manifests, source provenance and closed-Prop elaboration remain checked by the existing controller before model proofs start.
