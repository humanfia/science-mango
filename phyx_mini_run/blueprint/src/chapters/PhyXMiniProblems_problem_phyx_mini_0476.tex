\end{theorem}
\begin{proof}
The diagram identifies state 2 as one atmosphere, and the second leg from state 2 to state 3 is isobaric.  The isobaric pressure law therefore transfers the one-atmosphere pressure to state 3.  Inspecting the four displayed values $3,2,1,4$ shows that only choice C equals one.
\end{proof}
